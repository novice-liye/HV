# 三国历史可视化

> 一个多维度、可交互的三国历史（184-280年）综合可视化 Web 应用

**在线访问：[https://novice-liye.github.io/HV/](https://novice-liye.github.io/HV/)**

## ✨ 功能概览

| 模块 | 功能 |
|------|------|
| 📜 **时间线** | 多轨道时间轴，事件搜索（标题/人物/地点/年份/拼音），搜索高亮，缩放平移，势力/类别筛选 |
| 🗺️ **三国地图** | Leaflet 交互式地图，34省疆域填色，地点标记，行军路线动画，时间轴播放，著作标记 |
| 🕸️ **人物关系图** | Canvas 力导向图，123节点+254关系边，拼音搜索，势力筛选，关系路径搜索，全屏模式 |
| 🔍 **AI 搜索** | DeepSeek API 对话，SSE 流式输出，思考过程实时显示，联网搜索，Markdown 渲染 |
| 📚 **著作典籍** | 36部著作展示，类型筛选，详情弹窗，地图定位 |
| 👤 **人物图鉴** | 123位人物卡片，势力/年份筛选，搜索 |
| 📊 **数据仪表盘** | 统计图表可视化 |
| ⚔️ **战役沙盘** | 经典战役回放 |
| 🏠 **首页** | 模块导航入口 |
| ℹ️ **关于** | 项目技术文档 |

## 🛠️ 技术栈

- **框架**: React 19 + TypeScript
- **构建**: Vite 8
- **地图**: React-Leaflet 1.9
- **可视化**: Canvas API（力导向关系图）
- **AI**: DeepSeek API（SSE 流式 + 联网搜索）
- **Markdown**: react-markdown
- **样式**: CSS Variables 暗色古风主题

## 🎯 核心特性

### 模块联动
基于 EventBus 的跨模块通信机制，支持：
- 时间线事件点击 → 地图定位 + 关系图聚焦
- 地图地点点击 → 时间线跳转 + 关系图高亮
- 关系图人物点击 → 时间线筛选 + 地图定位
- 著作/人物卡片点击 → 跨模块跳转

### 搜索系统
- **多维度搜索**: 标题、描述、人物名、地点名、年份、拼音
- **年份范围**: 支持 `208` 单年份和 `200-220` 范围搜索
- **搜索高亮**: 白色边框闪烁动画 + 其他事件变暗
- **IME 兼容**: 中文输入法组合输入正确处理

### AI 智能问答
- **流式输出**: SSE 实时流式显示，思考过程和回复内容同步呈现
- **联网搜索**: 支持调用 DeepSeek web_search 工具获取实时信息
- **知识库**: 系统提示词内置完整项目数据作为三国知识库
- **Markdown 渲染**: 支持图片、链接、表格、代码块等富文本格式

### 地图交互
- **疆域演变**: 34 省按势力归属填色，随时间滑块动态变化
- **行军路线**: 赤壁之战、夷陵之战等经典战役行军动画
- **著作标记**: 36 部著作按地点分组，多部著作合并显示 + 数量徽章
- **三图层切换**: 疆域层 / 事件层 / 著作层独立控制

### 人物关系图
- **力导向布局**: Canvas 物理模拟，节点自动排列
- **关系类型**: 家族/君臣/敌对/对手/联盟，不同颜色区分
- **路径搜索**: BFS 算法查找两人之间的关系链
- **全屏模式**: Fullscreen API 沉浸式浏览
